Welcome to my personal website.

I built this space as a central hub for my work as a Design Engineer. It functions as three things at once: a portfolio of projects I have built, a custom component registry based on the shadcn/ui pattern, and a blog where I write technical notes and post-mortems.

## The Tech Stack

I wanted the site to be minimal, fast, and easy to maintain over time:

- **Next.js 16 (App Router)**: Fast server components, static generation for blog posts, and dynamic API routes for the registry.
- **Tailwind CSS v4**: Using the modern CSS-first theme configuration.
- **shadcn/ui**: Accessible base components with custom styling and extensions.

## A Few Features Built Into the Site

### Component Registry
Instead of just showing screenshots of UI components, I set up a registry following shadcn's distribution format. You can install components directly into your own projects with the CLI:

```bash
npx shadcn@latest add https://zephinax.com/r/react-picture-selector.json
```

The registry build script automatically generates the JSON schema files under `public/r/` on build.

### Markdown & LLM Friendly
- **Raw Markdown Access**: Every blog post can be viewed as raw markdown by appending `.md` to the URL (for example, [`/blog/welcome.md`](/blog/welcome.md)). This makes it convenient to read via terminal or curl.
- **AI-Agent Sitemap**: I added a [`/llms.txt`](/llms.txt) file summarizing my background, active projects, and links for LLMs and autonomous agents.

### Local-First Audio
The small click and unlock sounds in the command menu and widgets run on a custom `useSound` hook using the native Web Audio API. Audio buffers are cached locally, with a procedural oscillator fallback if files fail to load.
